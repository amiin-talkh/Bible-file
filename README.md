# 📖 Bible File (Mongolian)

Энэхүү төсөл нь **Ариун Библийн 66 номыг** хайлт хийх, презентаци бэлтгэх болон программ хангамжид ашиглахад хамгийн хялбар, цэвэрхэн нэгдмэл формат руу хувиргасан өгөгдлийн сан юм.

---

### 🌟 Гол онцлог ба давуу талууд

#### 1. Presentation & Nomlol (Презентаци, Номлолд ашиглах)
* **Шууд Copy / Paste:** Номлолын үеэр эсвэл цуглааны слайд бэлдэхэд тухайн ишлэлийг хайж олоод шууд PowerPoint, EasyWorship, Keynote рүү хуулж тавихад бэлэн.
* **Тайрч форматлах шаардлагагүй:** Номын нэр, бүлэг, ишлэлийн дугаар болон текст нь нэг мөрөнд стандартын дагуу бичигдсэн тул ямар нэгэн илүүдэл зааг, код харагдахгүй.

#### 2. EasyWorship ба Программд шууд импортлох
* **EasyWorship формат:** EasyWorship болон бусад сүм хийдийн презентацийн программ руу шууд текст хэлбэрээр импортлон ашиглах боломжтой.
* **Хайлтын системд тохиромжтой:** Нэг мөрөнд нэг ишлэл байрлах тул JavaScript, Python, C# зэрэг ямар ч хэл дээр хайлтын систем (*Search engine*) хийхэд маш хурдан бөгөөд хялбар.

---

### 📄 Форматын бүтэц

Өгөгдөл нь дараах форматаар хадгалагдсан:

```text
[Номын Нэр] [Бүлэг]:[Ишлэл] [Ишлэлийн Текст]
```

### 🔍 Notepad дээр ишлэл хурдан хайх заавар
`easyworship_bible.txt` файлыг **Notepad** (Тэмдэглэлийн дэвтэр) дээр нээгээд маш хурдан хайлт хийх боломжтой:

1. **Файлаа нээх:** `easyworship_bible.txt` файл дээрээ хоёр дарж Notepad дээр нээнэ.
2. **Хайлтын цонх гаргах:** Гарын дээрх **`Ctrl + F`** товчийг хамт дарна.
3. **Ишлэл эсвэл үгээ бичих:** 
   * **Тодорхой ишлэл хайх:** `Матай 5:2` эсвэл `Эхлэл 1:1` гэж бичээд **Enter** дарна.
   * **Түлхүүр үгээр хайх:** `хайр`, `ивээл`, `итгэл` гэх мэт хайх үгээ бичнэ.
4. **Хуулж авах:** Идэвхжиж гарч ирсэн мөрийг хуулж (**Ctrl + C**) авснаар PowerPoint, EasyWorship эсвэл бусад слайд руугаа шууд тавих (**Ctrl + V**) боломжтой.
